    # The Hahn-Banach theorem This file proves the Hahn-Banach theorem thanks to Zorn's lemma. Theorem `hahn_banach_extension` states that, considering `V` an lmodType on a realtype, a linear function on a subLmodType of V, that is bounded by a convex function, can be extended to a linear map on V bounded by the same convex function. Theorem `hahn_banach_extension_normed` specifies this to the extension of a linear continuous function defined on a subnormedmodule to the whole normed module. Theorem `hahn_banach_extension_subctvs` allows to extend a linear function defined on a subconvextvs to a convextvs. Theorem `hahn_banach_extension_initialsubctvs` allows to extend a linear function defined on a sublmodule to a convextvs. | Extension theorem | subcodomain | codomain | |--------------------------------------|------------------|---------------| | hahn_banach_extension | subLmodType | lmodType | | hahn_banach_extension_normed | subNormedmodType | normedModType | | hahn_banach_extension_subcvts | subconvextvsType | convexTvsType | | hahn_banach_extension_initialsubctvs | subLmodType | convexTvsType |
