# Differentiation This file provides basics of a theory of differentiation. It includes the standard rules of differentiation (differential of a sum, of a product, of exponentiation, of the inverse, etc.). Parsable notations (in all of the following, f is not supposed to be differentiable): `'d f x` : the differential of a function `f` at a point `x` `differentiable f x` : the function `f` is differentiable at a point `x` `is_diff x f df` : the differential of a function `f` at point `x` is `df` and `f` is : differentiable at point `x` Naming convention in this directory: - lemmas of the form `... -> is_diff x f df` are named `is_diff*` (e.g., `is_diff_cst`) ## Automatic differentiation and derivation with `is_diff` and `is_derive` NB: documentation below also applies to `derivative.v` Statements of the form `is_diff` and `is_derive` are typeclasses registered via `Instance` declarations with a proof `ex_derive`/`ex_diff` of derivability/differentiability of the expression and a proof `derive_val`/`diff_val` of the value of the derivative/differential of the function; so that typeclass resolution can automatically synthesize the differential/derivative of a compound expression from the differentials/derivatives of its parts, instead of requiring the user to prove and compute derivatives by hand. ## Lemmas of the form `is_diff` and `is_derive` For a compound expression, e.g., built from f and g, state the goal with the expected differential/derivative and let typeclass resolution fill the proof by `apply: is_diff_eq` or `apply: is_derive_eq`: ```coq Lemma is_derive_example (W : normedModType R) (t : R^o) (f g : R^o -> W) (f' g' : W) v : is_derive t v f f' -> is_derive t v g g' -> is_derive t v (f + g) (f' + g'). Proof. move => is_der_f is_der_g. by apply: is_derive_eq. Qed. ``` The proof is inferred structurally by chaining declared `is_diff` or `is_derive` instances matching the pattern of the goal stated. To verify if a given expression is differentiable or derivable, you can use `apply: ex_diff` or `apply: ex_derive`, given the right `is_diff _` or `is_derive _` instances are defined such as: ```coq Hypothesis derivable_f : forall t, derivable f t 1. Hypothesis derivable_h : forall t, derivable h t 1. Local Instance is_derive_f t : is_derive t 1 f ('D_1 f t). by apply: derivableP. Qed. Local Instance is_derive_h t : is_derive t 1 h ('D_1 h t). by apply: derivableP. Qed. Lemma is_derivable_example (t : R^o) : derivable (f + h) t 1. Proof. apply/ex_derive. Qed. ``` To verify the value of a given function you can apply `derive_val` or `diff_val`, given the right `is_derive/diff` instances are defined, e.g.: ```coq Lemma is_derive_val_example t : 'D_1 (f + h) t = 'D_1 f t + 'D_1 h t. Proof. by apply/derive_val. Qed. ```
